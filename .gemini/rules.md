# Project Rules for Antigravity

## Commit Extended Description Rule
Whenever making any changes to the website files or codebase:
1. Always write an EXTENDED DESCRIPTION for the commit message.
2. Structure the description in the following order:
   - File Path(s) modified: `Path: <path/to/file>`
   - Bulleted list of changes made.
   - Signature line at the very end: `change commit by Antigravity (<Conversation_ID_or_User_ID>)`
